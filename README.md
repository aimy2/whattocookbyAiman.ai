
# What to Cook by Aiman

What to Cook by Aiman is a personalized recipe discovery app. Users describe the kind of meal they want, choose flavor and location preferences, set an optional budget, and receive three recipe ideas generated by a locally running Ollama model.

## Features

- Mood-based recipe discovery: comforting, fresh and light, a little fancy, or quick win.
- Flavor preferences including savory, sweet, spicy, tangy, creamy, and crunchy.
- Continent, country, currency, and per-person budget filters.
- Local recipe generation through Ollama, with no hosted AI API key required.
- Generated recipe cards with ingredients, cooking steps, difficulty, ratings, and food images.
- Local saved recipes and a simple local login/profile experience.
- Responsive design for desktop and mobile screens.

## Tech Stack

- Next.js 16 with the App Router
- React 19 and TypeScript
- Tailwind CSS 4 through PostCSS
- Ollama for local AI recipe generation
- Pollinations image URLs for generated recipe artwork
- ESLint for code quality checks

## Requirements

Install the following before starting:

- Node.js 20.9 or newer
- npm
- Ollama
- The Ollama `llama3.2` model, or another compatible JSON-capable model

## Run Locally

### 1. Install dependencies

From the project directory:

```powershell
npm install
```

### 2. Install an Ollama model

Open PowerShell and download the default model:

```powershell
ollama pull llama3.2
```

Check that it is installed:

```powershell
ollama list
```

### 3. Start Ollama

Ollama Desktop normally starts the local service automatically. If it is not already running, start it with:

```powershell
ollama serve
```

If PowerShell reports that port `11434` is already in use, Ollama is probably already running. Do not start a second server; continue with the Next.js app.

### 4. Start the development server

```powershell
npm run dev
```

Open in your browser.

## Configuration

The app has sensible local defaults:

| Variable | Default | Purpose |
| --- | --- | --- |
| `OLLAMA_URL` | `http://localhost:11434/api/generate` | Ollama generation endpoint |
| `OLLAMA_MODEL` | `llama3.2` | Model used for recipe generation |

To use a different model or Ollama endpoint, create a `.env.local` file in the project root:

```env
OLLAMA_URL=http://localhost:11434/api/generate
OLLAMA_MODEL=llama3.2
```

Restart `npm run dev` after changing environment variables. Do not commit `.env.local` if it contains private credentials or deployment-specific values.

## How It Works

1. The home page collects the user's preferences and stores them in browser session storage.
2. The recipes page sends those preferences to `POST /api/recipes`.
3. The API route builds a structured prompt and sends it to Ollama with JSON output enabled.
4. The response is validated, normalized, and returned as three recipes.
5. Recipe cards and recipe details are rendered by the Next.js app.
6. Login state and saved recipe IDs are stored locally in the browser for this prototype.

## Troubleshooting

### `Ollama is unavailable`

Confirm that Ollama is running and that the model exists:

```powershell
ollama list
ollama run llama3.2
```

Close the interactive model prompt with `Ctrl+C`, then refresh the app. If you configured another model in `.env.local`, make sure the model name exactly matches the output of `ollama list`.

### `npm run dev` fails

Check the Node.js version and reinstall dependencies:

```powershell
node --version
Remove-Item -Recurse -Force node_modules
npm install
npm run dev
```

### Recipe images do not appear

Recipe images are loaded from `image.pollinations.ai`. The app needs an internet connection for those external images. Recipe generation itself still runs through your local Ollama service.
